# Riemann paper: DL baseline

Baseline for the Paul Barbaste Riemannian geometry EEG classification paper,
NeurIPS 2026. Private.

## Layout

| path | what |
|---|---|
| `notebooks/riemann_baseline_2026-08-27.ipynb` | handoff notebook, runs on CPU |
| `scripts/baseline_remturku.py` | cluster sweep + LOSO |
| `scripts/tuning_core.py` | optimizer, scheduler, train loop, copied verbatim from `tuning_p10_v3.py` |
| `riemann/` | model classes, unmodified, plus the de-Lightning'd `base_model` |
| `preprocessing/prepare_remturku.py` | REM_Turku pipeline, reproduces Sikka et al. 2019 |
| `analysis/` | mDES to VAD projection, FAA gate |
| `DATA_INVENTORY.md` | what exists, where, verified dates |

## Entry point for Paul

`evaluate(fit_predict, target)` in the notebook takes any callable with signature
`fit_predict(Xtr, ytr, Xte, seed) -> predictions` and returns the per-subject table.
Same subjects, folds, seeds, scaling and labels as the DL baseline. See notebook section 6.

## Data

Not in the repo. The local extract (87 MB, 6 subjects) is regenerated by the notebook's
loader from `remturku_local_extract.npz`. Full corpus lives on the MIT cluster at
`/orcd/scratch/orcd/010/ninon/reaDream/turku/`. Source is figshare
10.6084/m9.figshare.23274596.v2, CC-BY 4.0.

Known limitation: ShallowConv was NOT architecture-swept. Only `drop_prob` was passed;
its `filter_time_length` and `pool_time_length` defaults are tuned for 250 Hz while this
corpus is 500 Hz, so its temporal scales are halved. A corrected run is queued.
